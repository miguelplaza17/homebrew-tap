# Homebrew tap

```bash
brew trust miguelplaza17/tap
brew install --cask miguelplaza17/tap/skopos
```

Recent Homebrew asks you to trust a tap before it loads casks from it; that is the first line.

[Skopos](https://github.com/miguelplaza17/Skopos) is a light, simple, AI-ready database client. It updates itself after install.
